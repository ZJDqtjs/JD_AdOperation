## 1. 前置检查

- 容器 `jd-roi` 常驻，数据/登录态在 `/data`、`/auth`、`/config`。
- 脚本放 `/opt/jd-roi/docker-data/tmp`（容器内 `/data/tmp`），用容器执行：
  `docker exec -e PYTHONPATH=/app jd-roi python /data/tmp/xxx.py`
- 登录态检查：

```python
from jd_roi import config, browser
pw, context = browser.launch_profile(headless=True, account="acct2")
page = context.new_page()
page.goto(config.JZT_HOME, wait_until="domcontentloaded", timeout=90000)
page.wait_for_timeout(14000)
assert browser.session_ok(page)
print(browser.login_info(page))
```

> 不要和夜间抓取同时开浏览器；同一个持久化 Profile 只能一个进程用。

## 2. 写接口清单（统一走 atoms-api）

请求头：

```js
{'Content-Type':'application/json','accept':'application/json, text/plain, */*',
 'referer':'https://jzt.jd.com/','language':'zh_CN','siteid':'0','loginmode':'0'}
```

| 动作 | 接口 | 关键 body |
|---|---|---|
| 读计划配置 | `/dspad/msa/campaign/get` | `{"id":ID,"marketingObjective":1,"marketingScenario":1,"targetingType":2或8}` |
| 暂停/启用计划 | `/dspad/material/center/task/campaign/batch/update/status` | `{"campaignSettings":[{"campaignId":ID}],"operateType":1}` |
| 改日预算 | `/dspad/material/center/task/batchUpdate/bugdet` | `{"campaignSettings":[{"budgetSettings":{"unifiedBudget":N,"dayBudgetDetail":{},"increaseBudgetSwitch":0,"increaseBudgetRadio":20,"increaseBudgetExceptROI":null,"increaseBudgetMaxCount":3},"campaignId":ID}]}` |
| 改关键词出价 | `/dspad/material/center/task/batchUpdate/keyword/price` | `{"keywordTargetSetting":{"keywords":[{"id":KWID,"biddingPrice":"0.5","changeType":0,"bidType":1}]}}` |
| 人群启停 | `/dspad/material/center/task/batchUpdate/crowd/status` | `{"operateType":1,"groupSettings":[{"adGroupId":GID,"materialIds":CROWDID}]}` |
| 人群溢价 | `/dspad/material/center/task/batchUpdate/crowd/price` | `{"crowdSettings":[{"adGroupId":GID,"crowdId":CID,"crowdTabType":3,"crowdPriceCoef":15,"crowdType":2}]}` |
| 全站智能黑名单 | `/dspad/smartmax/skublack/update` | `{"campaignType":153,"campaignId":ID,"adGroupId":GID,"skuIds":[...]}`（全量覆盖） |
| 查黑名单 | `/dspad/smartmax/skublack/query` | `{"businessType":600000013,"campaignId":ID,"adGroupId":GID,"campaignType":153}` |
| 读关键词 | `/dspad/msa/promolist/item/keyword/keyword` | 行数据在 `data.data` |
| 读人群 | `/dspad/msa/promolist/item/keyword/crowd` | 行数据在 `data.data` |
| 读否定词 | `/dspad/msa/keyword/negative/list?requestFrom=0` | `{"adGroupId":GID,"marketingObjective":1,"marketingScenario":1,"targetingType":2}` |
| 否定词上限 | `/dspad/msa/keyword/negative/limit?requestFrom=0` | `{}` → `negativeWordNum`（当前 50） |

预算/人群接口里的 `strategyIdList`、`strategyVersionId` 可省略，平台按默认策略处理（实测成功）。

## 3. UI 入口（接口拿不到时）

| 操作 | 路径/选择器 |
|---|---|
| 暂停计划 | 计划列表行 `.name-switch-wrap .jad-switch`，点一下即生效，无二次确认 |
| 改日预算 | 计划头「日预算（¥）：」后的数字 → 右侧抽屉 `.jad-modal-slide-mask` → `input[placeholder='不限']` → 确定 |
| 改关键词出价 | 关键词页行内出价的铅笔 `i.jad-icon-pencil3` |
| 人群启停/溢价 | `#/list/tab/recommendDmp?...&activeTab=recommendDmp`；行开关；溢价铅笔 `i.set-unit-bid` |
| 否定词 | 关键词页 `button:has-text('否定词设置')` → `.jd-drawer.negative-word-drawer` → 输入 → 添加 → 确定 |
| 全站智能 ROI | `#/list/shopSmart?...&campaignType=153&targetingType=shopSmart&spuId=...`；`净成交投产比` 后的 `i.edit-icon` |
| SKU 黑名单 | 全站智能计划行「更多」→「设置SKU黑名单」→ 勾选 → 确认 |

> 否定词按钮不能用 `text=否定词设置` 定位，会命中隐藏抽屉标题；用 `button:has-text(...)`。

## 5. 口径与坑

1. 京准通是**点击后 15 天归因**，最近 5 天成交偏低；判断用稳定窗口（如 11/09–11/20），别用单日。
2. 保本 ROI 用 ERP 真实成本；平台 ROI 不能跨店直接比。
3. **日预算不得低于当日已消费**，报错文案：「当日自定义预算设置不得低于当日消费」。
4. **人群溢价最低 10%**，低于报 `crowd_premium_range`。
5. **否定词精确匹配**，上限 50；变体要拆开加。
6. **全站智能 ROI 只能降不能升**（上限≈当前值）；想升先退出稳赚保障。
7. 全站智能 153 是 SPU 级，SKU 花费按成员均分，SKU 级 ROI 仅作结构参考。
8. 快车 `status=3` 多为「预算用完」，`status=1` 才是暂停。
9. 暂停计划的预算仍保留但不花；「有效日预算」只算在投计划。
10. 2026-11-21 全账号只花 106 元（正常 950–1250），疑似余额/平台异常，不要当效果基线。

## 6. 复核清单（每次改完必跑）

- 计划：`campaign/get` → `status`、`dayBudget`
- 预算：`/dspad/common/budget/query` → `unifiedBudget`
- 关键词：重读 `promolist/item/keyword/keyword`
- 人群：重读 `promolist/item/keyword/crowd` + 页面开关 class
- 黑名单：`skublack/query`
- 否定词：`negative/list`

输出格式：

| 计划/单元 | 动作 | 修改前 | 修改后 | 校验结果 |
|---|---|---|---|---|

最后单列「未完成项 + 原因 + 建议下一步」。
